
# Abhinaya Machiraju — Student Portfolio

## About This Project
This is my personal student portfolio created for COMP-4001: Developing in a DevOps Environment at Red River College Polytechnic.

I customized the original portfolio template with my personal information, profile picture, skills, and academic projects.

## Technologies Used
- HTML and CSS
- Bootstrap
- Git and GitHub
- Docker
- Vagrant and CentOS

## Projects
1. Game Platform — A React and TypeScript application for managing games and reviews.
2. DevOps Environment Setup — Configured a CentOS virtual machine using Vagrant and VirtualBox.
3. Banking Web Application — Deployed a banking application using Docker.

## Docker Deployment
The portfolio runs in an NGINX container on port 3000.

The Banking App runs in a separate container on port 5090.

Both containers communicate through the `prf-network` Docker bridge network.
